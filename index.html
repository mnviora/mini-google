Random Surfer Dice Simulation

PageRank models a web surfer who navigates by following hyperlinks at random, but occasionally gets bored and jumps (teleports) to an arbitrary page. We simulate this random walk across 20 transitions starting at Page 1 using physical 6-sided dice rules.

Physical 6-Sided Dice Rules:
  • Start: Begin at Page 1 (initial placement is not counted as a visit).
  • Roll a Die Every Step (1-6):
    • Roll = 6 (Teleportation Trigger): The surfer gets bored! Roll the die a second time (1-6) to choose the destination page directly. The first 6 is not a visit to Page 6; only the destination of the second roll is counted.
    • Roll = 1 to 5:
      • If the page has 2 outgoing links: Odd roll (1, 3, 5) follows the 1st link; Even roll (2, 4) follows the 2nd link.
      • If the page has 1 outgoing link: Follow that single link directly.
      • If the page has 3+ links: Follow link index (roll - 1) % links.length.
      • If the page has 0 links: Jump to an arbitrary page uniformly at random.
